# proteomics-mcp v0.1.1

This release broadens the package from a narrower spectrum-scoring prototype into a more usable spectrum-ingestion and ID-normalization toolchain.

## What is new

### 1. Broader spectrum conversion support

You can now convert:

- `mzML` to Feather
- `MGF` to Feather
- Bruker `.d` directories to Feather

Bruker conversion prefers direct AlphaTims extraction and falls back to an embedded `ProteinAnalysisResults.mgf` export when present.

### 2. InstaNovo-ready spectrum export

Normalized Feather or IPC spectrum tables can now be exported into an InstaNovo-ready layout with:

- Arrow IPC output
- Parquet output
- optional `sequence` inclusion for annotated datasets

This makes it easier to move from raw spectral conversion into downstream InstaNovo prediction workflows.

### 3. Broader modification handling

Modification normalization is no longer limited to a tiny hand-maintained list.

The package now:

- keeps the existing common aliases for common PTMs
- resolves named modifications through the installed UNIMOD catalog when possible
- supports direct `UNIMOD:n` tags
- keeps numeric mass-delta support for fragment mass handling

### 4. Better search-engine adapter coverage

The current adapter surface includes:

- InstaNovo
- MaxQuant
- FragPipe
- Proteome Discoverer
- generic mapped tables

The current FragPipe path includes modification-aware peptidoform reconstruction from `Assigned Modifications` and `Modified Peptide` fields.

## Quick start

Convert a Bruker run:

```bash
uv run proteomics-mcp bruker-d-to-feather \
  --d-path input.d \
  --output-path spectra.feather
```

Export the result to an InstaNovo-ready IPC table:

```bash
uv run proteomics-mcp export-to-instanovo \
  --input-path spectra.feather \
  --output-path instanovo_input.ipc \
  --format ipc
```

## Important caveats

- Bruker `.d` extraction on macOS may rely on estimated `m/z` and mobility values when vendor libraries are unavailable.
- The project is currently distributed through GitHub releases only; there is no PyPI publishing yet.
- The easiest installation path is still a local checkout plus `uv sync`.

## Validation status

Release preparation included:

- package build validation with `uv build`
- CLI entrypoint validation with `uv run proteomics-mcp --help`
- focused regression testing over adapters, modification handling, spectrum conversion, and InstaNovo export

## Who should use this release

This release is useful if you want to:

- normalize PSM outputs from multiple search/de novo tools
- inspect modified peptidoforms consistently
- convert local spectra into a uniform Arrow/Feather representation
- bridge those tables into downstream InstaNovo workflows
