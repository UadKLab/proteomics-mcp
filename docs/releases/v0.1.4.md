# proteomics-mcp v0.1.4

This release adds a new upstream adapter and tightens the spectrum rendering workflow in ways that matter for interactive review.

The two main user-facing changes are:

- Casanovo output can now be normalized through the same candidate-loading surface as the existing InstaNovo, MaxQuant, FragPipe, Proteome Discoverer, and generic adapters.
- Mirror and annotated spectrum views now support optional fragment-ion subsequence labels through an in-plot checkbox, and wheel/trackpad scroll zoom is enabled directly in the Plotly views.

## What is new

### 1. Casanovo adapter support

`proteomics-mcp` now supports Casanovo-style prediction tables through `adapter="casanovo"`.

The adapter:

- reads Casanovo CSV exports with `predictions`, `log_probs`, precursor fields, and run grouping
- normalizes named modifications into UNIMOD-style peptidoforms
- converts sequence log probability to a 0-1 confidence using `exp(log_probs)`
- preserves the original input row in `source_columns`

This keeps Casanovo aligned with the existing canonical `CandidatePSM` contract instead of creating a parallel code path.

### 2. Optional fragment-ion subsequences in rendered spectra

The mirror plot and annotated observed-spectrum plot now include a checkbox:

- `Show fragment ion sequences`

When enabled, fragment labels expand from ion-only notation such as:

- `b3+`
- `y6+`

to sequence-aware labels such as:

- `b3+ | PEP`
- `y6+ | TIDE`

This is a visualization-layer feature only. It does not change scoring, matching, or annotation logic.

### 3. Better interactive zoom behavior

Rendered spectra now support wheel / trackpad scroll zoom directly in the Plotly canvas.

That reduces friction when inspecting dense local peak neighborhoods and removes the need to rely only on box zoom or toolbar controls.

### 4. Updated example set

A fresh example folder is included for the TDYMVGSYGPR PSMs with the new rendering behavior:

- `examples/20_fragment_sequence_toggle_tdymvgsygpr/`

It contains mirror, annotated, and observed-only HTML outputs for the same three peptide-level PSM examples used in the current regenerated set.

## Quick start

Load Casanovo candidates through the usual workflow surface:

```bash
uv run proteomics-mcp load-candidates --path casanovo_predictions.csv --adapter casanovo
```

Render the updated mirror or annotated views as usual; the subsequence checkbox is embedded in the generated HTML automatically.

## Important caveats

- The Casanovo adapter does not invent scan identifiers when the source file does not contain them.
- For scoring against local spectra, Casanovo exports still need a usable spectrum locator such as `scan_number`, `spectrum_id`, `usi`, or run-plus-scan mapping.
- The fragment-sequence control affects display text only; hover, scoring metrics, and matching thresholds are unchanged.

## Validation status

Release preparation included:

## Who should use this release

This release is useful if you want to:

- ingest Casanovo outputs without custom one-off parsing
- inspect matched fragments with more sequence context in the browser
- use scroll zoom during spectrum review instead of relying only on selection-based zoom
