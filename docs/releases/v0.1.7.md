# Proteomics MCP v0.1.7

## Changes

- Added a Claude Desktop `.mcpb` extension using the managed `uv` Python runtime.
- Updated extension metadata to MCPB manifest v0.4 and aligned GitHub links with the UadKLab repository.
- Added MCP tool titles and read/write safety annotations for directory review.
- Documented three example workflows, local file handling, optional network requests, and the project's privacy policy.
- Prepared PyPI package metadata and aligned the Python package version with this release.
- Made common methyl and formyl UNIMOD lookups work without downloading the external catalog.

The extension runs locally with access to files selected by the user. Optional Koina, USI, and PRIDE functions use external services as documented in `PRIVACY.md`.
