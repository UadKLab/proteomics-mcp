# Proteomics MCP v0.1.8

This is the first release from the clean public repository snapshot. It prepares the Python package for a separate, manual first PyPI publication. Scientific scoring behavior is unchanged from v0.1.7.

## Changes

- Document direct `pip` and `uvx` installation and use absolute documentation links that render correctly on PyPI once the repository is public.
- Correct the interactive HTML description: Plotly is loaded from a CDN, not bundled into a fully offline report.
- Replace machine-specific paths in prompt-example navigation with portable relative links.
- Validate package version, tests, and Python distributions in the GitHub release workflow; require an existing matching release tag for manual PyPI publication.
- Add a MkDocs documentation site and a GitHub Pages workflow that deploys only after the repository is public.
- Remove local-machine paths from tracked example payloads and archive documentation.
- Add citation metadata using the final manuscript author list.
- Link the manuscript's supplementary data and figure evidence at [Zenodo](https://doi.org/10.5281/zenodo.23295902). The original mass-spectrometry files remain in PRIDE under PXD044934, PXD014877, and PXD010595.

PyPI publication is not part of this GitHub release and remains a separate manual step.
